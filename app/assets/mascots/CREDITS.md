# Mascot artwork credits and licenses

This file records the provenance, authorship and license of every mascot asset
used by the decorative mascot layer (`app/components/mascots/`). Animated rigs
live as Vue components, which are the source of truth for the artwork. Vue
template comments are stripped from production builds, so the visible credit is
the footer line (`footer.mascotCredit` in `i18n/locales/*.json`).

## Rig and animation conventions

- [`svg-mascot-creator`](https://github.com/Abhiramdadi17/Mascot-skill) by
  Abhiram Dadi — MIT, Copyright (c) 2026 Abhiram Dadi. Installed verbatim at
  `.claude/skills/svg-mascot-creator/` (license file included there). The
  fixed-rig conventions (stable group IDs, transform-only animation,
  anchor-based pivots, amplitude caps, reduced-motion gating) and the
  [`clawd-emotes`](https://github.com/xixicc186/clawd-emotes-skill) structural
  rules (feet inside the body group, props inside the moving arm's group,
  per-character keyframe prefixes) are followed in `app/assets/css/mascots.css`.
  Exception: in the exercise scene each dumbbell is a persistent group outside
  the arm groups, with its path generated to match the claw's grip point (see
  `scripts/gen-mascot-exercise.py`).
